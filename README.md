# Estatística Projeto 01 — Pesquisa Simples

## Objetivo
Aplicar fundamentos de estatística por meio da criação de uma pesquisa simples, coleta de dados reais e organização inicial para análise.

## Tema
Perfil de estudo de estudantes.

## Problema de Pesquisa
Qual é o perfil básico de estudo de estudantes em relação à idade, altura, curso e tempo diário de estudo?

## Tipo de Estatística
Estatística Descritiva com dados amostrais.

## População
Estudantes.

## Amostra
Entre 20 e 50 estudantes respondentes.

## Variáveis Coletadas
- Idade
- Altura
- Curso
- Tempo de estudo por dia

## Estrutura do Projeto
- `data/raw/` → dados brutos
- `data/processed/` → dados tratados
- `docs/` → documentação
- `notebooks/` → análises
- `src/` → scripts Python
