# Documento que formaliza a pesquisa. 8 blocos

# Plano de Pesquisa

## 1. Tema
Perfil de estudo de estudantes.

## 2. Problema de Pesquisa
Qual é o perfil básico de estudo de estudantes em relação à idade, altura, curso e tempo diário de estudo?

## 3. Objetivo Geral
Coletar e organizar dados básicos de estudantes para identificar e classificar características relacionadas ao seu perfil de estudo.

## 4. Objetivos Específicos
- Coletar dados de estudantes por meio de formulário.
- Organizar os dados em uma base estruturada.
- Classificar as variáveis coletadas.
- Diferenciar população e amostra.
- Preparar os dados para análise estatística.

## 5. Tipo de Estatística
Este projeto utiliza Estatística Descritiva, com foco na coleta, organização, classificação e descrição de dados amostrais.

## 6. População e Amostra
- População: estudantes.
- Amostra: entre 20 e 50 estudantes respondentes.

## 7. Variáveis
- Idade
- Altura
- Curso
- Tempo de estudo por dia

## 8. Metodologia de Coleta
Os dados serão coletados por meio de um formulário digital (Google Forms), contendo perguntas objetivas sobre o perfil acadêmico dos respondentes. Após a coleta, os dados serão exportados em formato CSV para organização e análise.
